# Standard SEC-14: Firmware Security

SEC-14 requires that all field-deployed radios and controllers run cryptographically signed
firmware. Unsigned images and rollbacks below the signed baseline are prohibited.

## Scope

- SkyLink X2 telemetry radio line (NimbusOne, HaloDock links).
- HaloDock dock controllers.

## Compliance

Firmware releases such as SkyLink X2 2.3.2 ship signed images and satisfy SEC-14. Compliance is
audited quarterly by Marcus Webb's firmware team.
